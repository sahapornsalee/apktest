# ดูต่อเนื่อง (AutoPlayVideo)

แอป Android สำหรับดูวิดีโอในเครื่องที่โหลดมาไว้หลายตอน/หลายภาค ให้เล่นต่อกันเองอัตโนมัติ และข้ามเพลงเปิด/เพลงปิดได้

## ความสามารถ
- เลือก **ทั้งโฟลเดอร์** (รวมโฟลเดอร์ย่อย เช่น ภาค 1, ภาค 2) หรือเลือกหลายไฟล์ แอปจะเรียงตอนให้เอง (EP2 มาก่อน EP10)
- จบตอนแล้วเล่นตอนต่อไปทันที ไม่ต้องกดเอง
- ตั้งเวลา **ข้ามเพลงเปิด** (เริ่ม–จบ) และ **ข้ามเพลงปิด** (กี่วินาทีสุดท้าย) ครั้งเดียว ใช้กับทุกตอนในเรื่องนั้น
- ระหว่างดู แตะจอแล้วกด “☰ เมนู” → “⏱ ตอนนี้ = จุดเริ่ม/จบเพลงเปิด” หรือ “จุดเริ่มเพลงปิด” เพื่อตั้งเวลาจากตำแหน่งที่กำลังดูได้เลย
- **จัดหมวดหมู่** ได้ (เพิ่ม/เปลี่ยนชื่อ/เลื่อนลำดับ/ลบ/ยุบ-ขยาย) และย้ายเรื่องข้ามหมวดได้
- แก้ไขได้ทั้งหมด: เปลี่ยนชื่อเรื่อง/ตอน, เพิ่ม/ลบตอน, เลื่อนลำดับตอน, เรียงตามชื่อไฟล์ใหม่
- ตั้งเวลาข้ามเพลง **เฉพาะบางตอน** ได้ (เช่น หนังแต่ละภาคเพลงยาวไม่เท่ากัน)
- จำตำแหน่งการดู **แยกทุกคลิป** ละเอียดถึงวินาที (ค้างที่ 12:34 / 45:00) และรู้ว่าตอนไหนดูจบแล้ว
- ปุ่ม **ดูต่อล่าสุด** บนหน้าแรก กดทีเดียวกลับไปตอนและวินาทีที่ดูค้างไว้
- **รีเซ็ตการดู** ได้ทั้งแบบทีละตอน ทั้งเรื่อง หรือทุกเรื่อง

## ดาวน์โหลด APK
ไปที่หน้า **Releases** ของ repo นี้ แล้วโหลดไฟล์ `AutoPlayVideo-v1.0.N.apk` ล่าสุดมาติดตั้ง
(ต้องอนุญาต “ติดตั้งแอปที่ไม่รู้จัก” ในเครื่อง) รองรับ Android 8.0 ขึ้นไป

## Build เอง
```
./gradlew assembleRelease
```
ไฟล์จะอยู่ที่ `app/build/outputs/apk/release/app-release.apk`
ทุกครั้งที่ push ขึ้น GitHub, workflow `.github/workflows/build.yml` จะ build และสร้าง Release ให้อัตโนมัติ
