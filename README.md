# ดูต่อเนื่อง (AutoPlayVideo)

แอป Android สำหรับดูวิดีโอในเครื่องที่โหลดมาไว้หลายตอน/หลายภาค ให้เล่นต่อกันเองอัตโนมัติ และข้ามเพลงเปิด/เพลงปิดได้

## ความสามารถ
- เลือก **ทั้งโฟลเดอร์** (รวมโฟลเดอร์ย่อย เช่น ภาค 1, ภาค 2) หรือเลือกหลายไฟล์ แอปจะเรียงตอนให้เอง (EP2 มาก่อน EP10)
- จบตอนแล้วเล่นตอนต่อไปทันที ไม่ต้องกดเอง (ปิดได้ทีละเรื่อง ให้หยุดรอเมื่อจบแต่ละตอน)
- ตั้งเวลา **ข้ามเพลงเปิด** (เริ่ม–จบ) และ **ข้ามเพลงปิด** (กี่วินาทีสุดท้าย) ครั้งเดียว ใช้กับทุกตอนในเรื่องนั้น
- ระหว่างดู แตะจอแล้วกด “☰ เมนู” → “⏱ ตอนนี้ = จุดเริ่ม/จบเพลงเปิด” หรือ “จุดเริ่มเพลงปิด” เพื่อตั้งเวลาจากตำแหน่งที่กำลังดูได้เลย
- **จัดหมวดหมู่** ได้ (เพิ่ม/เปลี่ยนชื่อ/เลื่อนลำดับ/ลบ/ยุบ-ขยาย) และย้ายเรื่องข้ามหมวดได้
- แก้ไขได้ทั้งหมด: เปลี่ยนชื่อเรื่อง/ตอน, เพิ่ม/ลบตอน, เลื่อนลำดับตอน, เรียงตามชื่อไฟล์ใหม่
- ตั้งเวลาข้ามเพลง **เฉพาะบางตอน** ได้ (เช่น หนังแต่ละภาคเพลงยาวไม่เท่ากัน)
- จำตำแหน่งการดู **แยกทุกคลิป** ละเอียดถึงวินาที (ค้างที่ 12:34 / 45:00) และรู้ว่าตอนไหนดูจบแล้ว
- ปุ่ม **ดูต่อล่าสุด** บนหน้าแรก กดทีเดียวกลับไปตอนและวินาทีที่ดูค้างไว้
- **รีเซ็ตการดู** ได้ทั้งแบบทีละตอน ทั้งเรื่อง หรือทุกเรื่อง
- แตะสองครั้งซ้าย/ขวาเพื่อกรอ ±10 วินาที, ปุ่ม 🔒 ล็อกหน้าจอกันมือโดน
- ⏾ ตั้งเวลาปิด (15–90 นาที / หยุดเมื่อจบตอนนี้ / ดูอีกตอนเดียวแล้วหยุด)
- นับถอยหลัง 5 วินาทีก่อนไปตอนต่อไป หรือแสดงปุ่ม “ข้ามเพลงเปิด / ตอนต่อไป” ให้กดเอง แบบ Netflix
- ภาพตัวอย่างและแถบความคืบหน้าของทุกตอน, ค้นหาเรื่อง/ตอน, ปักหมุดเรื่องไว้บนสุด
- จอลอย (PiP) และเล่นเสียงต่อเมื่อปิดจอ พร้อมปุ่มควบคุมบนแถบแจ้งเตือน
- หมุนจออัตโนมัติตามคลิป (รองรับคลิปแนวตั้ง) และปรับขนาดภาพ พอดีจอ/ตัดขอบ/ยืด จำแยกทีละเรื่อง
- 🎨 เปลี่ยนธีม (ตามระบบ / สว่าง / มืด / ดำสนิท) และสีหลักของแอปได้ 11 สี

## หน้าตาแบบ Netflix
- หน้าแรก: แบนเนอร์ใหญ่ “ดูต่อล่าสุด” + แถวเลื่อนแนวนอนแยกตามหมวดหมู่ (ดูต่อ / ปักหมุด / หมวดต่างๆ)
- หน้าเรื่อง: ภาพใหญ่ ปุ่ม ▶ สีขาว แถบเหลือเวลา และรายการตอนพร้อมภาพตัวอย่าง แบ่งตามภาค (โฟลเดอร์ย่อย)
- หน้าเล่น: ปุ่ม ↺10 ▶ ↻10 กลางจอ, แถบเวลา, แถวปุ่ม ความเร็ว / ล็อก / ตอน / เสียงและซับ / ตอนต่อไป
- ปุ่ม “ตอน” เปิดแผงเลือกตอนแบบ Netflix เลื่อนดูภาพตัวอย่างได้, ปุ่ม ⟳ หมุนจอกดครั้งเดียวสลับแนวตั้ง/แนวนอน (แตะค้าง = อัตโนมัติ)
- จำความเร็ว เสียงพากย์ และซับไตเติลที่เลือกไว้ทีละเรื่อง

## รองรับไฟล์วิดีโอ
- นามสกุลที่สแกนเจอ: mp4, m4v, mkv, webm, mov, 3gp, ts, mts, m2ts, avi, divx, xvid, wmv, asf, flv, f4v, mpg, mpeg, vob, ogv, rm, rmvb, mxf ฯลฯ
- ตัวเล่นหลัก (ExoPlayer) + ตัวถอดรหัสเสียง FFmpeg (AC3, E-AC3, DTS, TrueHD ฯลฯ)
- ตัวเล่นของระบบ (Android MediaPlayer แบบเดียวกับแอปวิดีโอในเครื่อง) สำหรับไฟล์ที่ตัวเล่นหลักเปิดไม่ได้หรือภาพแตก
- ตัวเล่นสำรอง VLC สำหรับไฟล์ที่ตัวเล่นหลักเปิดไม่ได้หรือภาพแตก (เลือกถอดรหัสด้วยซอฟต์แวร์ได้)
- โหมดอัตโนมัติ: avi/wmv/rmvb/mpg/m2ts ฯลฯ เปิดด้วย VLC, ไฟล์อื่นใช้ตัวเล่นหลัก ถ้าตัวเล่นหลักเล่นไม่ได้จะลองตัวเล่นของระบบ แล้วค่อย VLC

## ดาวน์โหลด APK
ไปที่หน้า **Releases** ของ repo นี้ แล้วโหลดไฟล์ `AutoPlayVideo-v1.0.N.apk` ล่าสุดมาติดตั้ง
(ต้องอนุญาต “ติดตั้งแอปที่ไม่รู้จัก” ในเครื่อง) รองรับ Android 8.0 ขึ้นไป

## Build เอง
```
./gradlew assembleRelease
```
ไฟล์จะอยู่ที่ `app/build/outputs/apk/release/app-release.apk`
ทุกครั้งที่ push ขึ้น GitHub, workflow `.github/workflows/build.yml` จะ build และสร้าง Release ให้อัตโนมัติ
